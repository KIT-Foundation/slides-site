## Що це за проєкт


## Роль агента


## 1. Структура проєкту

```
.
├── AGENTS.md                  # Цей файл. Інструкції для агента.
├── README.md                  # Опис проєкту. Агенту заборонено читати цей файл без прямого наказу користувача.
├── inbox/                     # Тимчасовий буфер для вхідних файлів чи каталогів. Агенту заборонено додавати до нього та до його підкаталогів файли чи інші каталоги без прямого наказу користувача.
|   └── assets/                # Тимчасовий буфер для вхідних медіа-файлів.
├── CITATION.cff               # Метадані репозиторію та цитування.
├── temp/                      # Каталог для тимчасових файлів (ігнорується Git)
└── .obsidian/                 # Налаштування Obsidian. Агенту заборонено читати або редагувати цей каталог і його вміст без прямого наказу користувача.
```

## 2. Загальні конвенції

1. **Робота з git**: Заборонено робити `git add`, `git commit`, `git push` та `git pull` без прямого наказу користувача.
2. **Робота зі структурою**: При додаванні нових каталогів до структури проєкту агент зобов'язаний занести їх у розділ 1 цього файлу.
3. **Робота з тимчасовими файлами**: Заборонено створювати тимчасові файли (скрипти, нотатки тощо) поза межами `temp/` — тимчасові файли розміщуються лише в цьому каталозі.
4. **Стиль іменування файлів та каталогів**: Завжди використовуй англійську мову та `kebab-case` стиль іменування. Виняток: прямий наказ користувача використовувати інший стиль.
